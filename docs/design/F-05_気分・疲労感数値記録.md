# F-05 気分・疲労感数値記録 — 機能設計書

> 共通事項は [設計書](../設計書.md) を参照。保存 API（R-03）は [F-04](F-04_3食食事記録・日記入力.md) と共通。グラフ表示は [F-06](F-06_体調追跡グラフ自動生成.md)。

| 項目 | 内容 |
| :--- | :--- |
| 機能ID / 優先度 | F-05 / 必須 |
| 画面 | W-03 メイン画面（PC）、W-06 メイン画面（スマホ） |
| API | R-03 サマリーの保存（表示は R-01） |
| テーブル | daily_summaries（C/R/U） |

## 1. 概要

日ごとに、次の3つの数値を5刻みで記録する。原紙の書式に対応する。

| 項目 | 記入のタイミング | 原紙での位置 | 値 |
| :--- | :--- | :--- | :--- |
| 朝の気分（◯） | 朝、起きたとき | グラフの◯ | 5〜100の5刻み（大きいほど良い） |
| 疲労感（△） | 1日の終わり | グラフの△ | 5〜100の5刻み（大きいほど強い） |
| 1日の気分（％） | 夜、1日の総合 | 右端の「1日の気分」列 | 5〜100％の5％刻み |

「1日の気分」は、朝の気分とは別の項目で、グラフには載せない（右端の列に数値で出す）。多くの利用者が「だいたいの数値」で記入しているため、自由入力ではなく **5％刻みの選択式**にする。

## 2. 画面（W-03・W-06 の数値の領域）

| 項目 | 種別 | 入力チェック |
| :--- | :--- | :--- |
| 朝の気分（◯） | 選択（5, 10, …, 100）または未入力 | 5〜100の5刻み、任意 |
| 疲労感（△） | 選択（5, 10, …, 100）または未入力 | 5〜100の5刻み、任意 |
| 1日の気分（％） | 選択（5％, 10％, …, 100％）または未入力 | 5〜100の5刻み、任意 |

- 選択式にして、5刻み以外の値を入力できないようにする。**PC** は、押しやすい大きさのセレクトまたはボタン群。
- **スマホ**（W-06）の入力は 2.1 のとおり。朝の気分（◯）は5刻みのドラムロール、1日の気分（％）は顔絵文字5つとドラムロール、疲労感（△）はバッテリー型スライダー（「元気の残量」）。手書きの記録表の「ざっくりとした主観的な記入」の感覚を再現し、気分が落ちているときでも直感的に選べるようにする。
- スマホのドラムロールの先頭には、未入力に戻すための「未入力」を置く（20段階には数えない）。選択を確定したときに、その項目だけを R-03 で送る。
- 選択を解除すると未入力に戻せる。
- 保存のタイミング: 選択した時点で、その項目だけを R-03 で送る。

### 2.1 スマホの入力（W-06）

「ざっくりとした主観的な記入」の感覚を保ちながら、提出用 PDF（W-05）の数値は厳密に保つ。保存する値（API・DB）は PC と同じで、スマホの表示・操作だけが異なる。

| 項目 | スマホの入力 |
| :--- | :--- |
| 朝の気分（◯） | 5刻みのドラムロール（5〜100の全20段階。先頭に「未入力」） |
| 1日の気分（％） | **顔絵文字**を5つ並べる（😆 100%、🙂 75%、😐 50%、🙁 25%、😢 5%）。顔を1回タップすると、その値が入る（保存される）。あとからドラムロールで5%刻みに微調整できる。現在の値が5つの値と一致するときだけ、その顔を選択中として表示する。各顔に文字（とても良い・良い・ふつう・悪い・とても悪い）と `aria-label` を添え、絵だけに頼らない。**提出用 PDF（W-05）には顔絵文字を出さず、数値の文字だけを出す** |
| 疲労感（△） | 横向きの大きな**バッテリー型のスライダー**。ボックスの中を指で触って右へスライドすると、ゲージが指に吸着して満ちていく（5%刻みのステップで吸着）。選ぶ値は「**元気の残量**」 |

**疲労感の変換（元気の残量 → 疲労感の強さ）**

- 保存・グラフ・PDF で使う値は、これまでどおり**疲労感の強さ**（5〜100、大きいほど強い）。スマホの「元気の残量」からは、`疲労感 = 100 − 元気の残量` で自動で変換する（例: 残量 20% → 疲労感 80）。画面に表示するときは逆に、`元気の残量 = 100 − 疲労感` で戻す。
- 残量の選べる範囲は **0〜95%**（5%刻みの全20段階）。疲労感の下限が5のため、残量100%（疲労感0）は選べない。残量 0% は疲労感 100、残量 95% は疲労感 5 に対応する。
- 変換は、フロントエンドの**1つの関数だけ**で行う（保存前の変換、表示のための逆変換）。API・DB・W-05・F-06 のグラフは、疲労感の強さのまま変わらない（例: 残量 20% の日は、グラフの△が 80 の位置に出る）。
- 色と言葉: 残量に応じて、ゲージの色と言葉がリアルタイムで変わる。残量 0〜20% は赤で「限界…」、25〜75% は黄で「ちょっと疲れた」、80〜95% は緑で「まだ元気」。色だけに頼らず、言葉と残量の数字（％）も表示する。
- 未入力: 初めはゲージのない空のボックスで、「未入力」と表示する。「クリア」ボタンで未入力に戻せる。指を離したとき（確定）に、その項目だけを R-03 で送る（`fatigue` に変換後の値）。
- 操作の代わり: スライダーは `role="slider"` とし、`aria-valuenow`（残量）、`aria-valuetext`（例「元気の残量 20%、疲労感の強さ 80」）を付ける。矢印キーで5%ずつ動かせる。
- PC の W-03 は、従来どおり「疲労感（△）」を5〜100の強さで選ぶ（大きいほど強い）。同じ日でも、PC は強さ、スマホは残量で表示される（同じ値の裏表）。

## 3. API

R-03（[F-04](F-04_3食食事記録・日記入力.md) の定義）を使う。

```json
// 入力
{ "morning_mood": 30, "fatigue": 15, "day_mood": 35 }
// 入力（未入力に戻す）
{ "day_mood": null }
```

| 検証 | 内容 |
| :--- | :--- |
| `morning_mood` / `fatigue` / `day_mood` | 任意（null 可）、整数、5〜100、5の倍数 |

| ステータス | 条件 |
| :--- | :--- |
| 422 | 範囲外（0、105）、5の倍数でない（33）、整数でない |

## 4. データ

- `daily_summaries.morning_mood` / `fatigue` / `day_mood`（tinyint unsigned、NULL 可）。5の倍数であることはアプリ側で検証する。

## 5. 振る舞い

- 保存の流れは F-04 と同じ。保存に成功したら、F-06 のグラフを再描画する（サーバーからの再取得はせず、画面の状態を更新する）。`day_mood` は右端の列に反映する。

## 6. 受け入れ条件とテスト観点

| 受け入れ条件 | 観点 |
| :--- | :--- |
| 5〜100の5刻みで3項目を保存でき、再表示で同じ値が出る | 正常: 朝の気分30、疲労感15、1日の気分35 |
| 未入力に戻せる | 正常: null |
| 範囲外・5刻みでない値は拒否される | 異常: 0、3、33、105、"abc"、30.5 |
| 境界の値が通る | 境界: 5 と 100 |
| 朝の気分・疲労感の保存でグラフが更新される | 手動確認（F-06） |
| 1日の気分は右端の列に出て、グラフには載らない | 手動確認（F-06・F-07） |
| スマホで朝の気分がドラムロール（全20段階）で選べる | 手動確認（5、10、…、100。テキスト入力はできない） |
| スマホで「未入力」を選ぶ、または疲労感の「クリア」を押すと未入力に戻る | 正常: 手動確認（R-03 に null が送られる） |
| 顔絵文字をタップすると、1日の気分に 100/75/50/25/5 が入り、ドラムロールで微調整できる | 手動確認（顔ごとの値。微調整後は顔の選択表示が消える） |
| 提出用 PDF に、顔絵文字ではなく数値だけが出る | 手動確認（W-05。F-07） |
| 元気の残量から疲労感が正しく変換される | 正常: 残量 20 → 疲労感 80、残量 0 → 100、残量 95 → 5（保存値 `fatigue`。Claude in Chrome で確認） |
| 疲労感の保存値が、スマホの残量表示に正しく戻る | 正常: 疲労感 80 の日は残量 20%。PC で疲労感 5 を保存した日は、スマホで残量 95% |
| 残量 100%（疲労感 0）は選べない | 境界: スライダーの最大が 95%（手動確認） |
| 残量に応じて、ゲージの色と言葉が変わる | 境界: 20%（赤・限界…）、25%（黄）、75%（黄）、80%（緑・まだ元気）（手動確認） |
| スマホで入力した疲労感が、W-03・W-05・F-06 のグラフに強さ（変換後の値）で出る | 正常: 残量 20% の日、グラフの△が 80（手動確認） |
