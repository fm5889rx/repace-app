# F-05 気分・疲労感数値記録 — 機能設計書

> 共通事項は [設計書](../設計書.md) を参照。保存 API（R-03）は [F-04](F-04_3食食事記録・日記入力.md) と共通。グラフ表示は [F-06](F-06_体調追跡グラフ自動生成.md)。

| 項目 | 内容 |
| :--- | :--- |
| 機能ID / 優先度 | F-05 / 必須 |
| 画面 | W-03 メイン画面（記録表） |
| API | R-03 サマリーの保存（表示は R-01） |
| テーブル | daily_summaries（C/R/U） |

## 1. 概要

日ごとに、次の3つの数値を5刻みで記録する。原紙の書式に対応する。

| 項目 | 記入のタイミング | 原紙での位置 | 値 |
| :--- | :--- | :--- | :--- |
| 朝の気分（◯） | 朝、起きたとき | グラフの◯ | 5〜100の5刻み（大きいほど良い） |
| 疲労感（△） | 1日の終わり | グラフの△ | 5〜100の5刻み（大きいほど強い） |
| 1日の気分（％） | 夜、1日の総合 | 右端の「1日の気分」列 | 5〜100％の5％刻み |

「1日の気分」は、朝の気分とは別の項目で、グラフには載せない（右端の列に数値で出す）。多くの利用者が「だいたいの数値」で記入しているため、自由入力ではなく **5％刻みの選択式**にする。

## 2. 画面（W-03 の数値の領域）

| 項目 | 種別 | 入力チェック |
| :--- | :--- | :--- |
| 朝の気分（◯） | 選択（5, 10, …, 100）または未入力 | 5〜100の5刻み、任意 |
| 疲労感（△） | 選択（5, 10, …, 100）または未入力 | 5〜100の5刻み、任意 |
| 1日の気分（％） | 選択（5％, 10％, …, 100％）または未入力 | 5〜100の5刻み、任意 |

- 選択式にして、5刻み以外の値を入力できないようにする。**PC** は、押しやすい大きさのセレクトまたはボタン群。
- **スマホ**（`md` 未満）は、3項目（朝の気分◯・疲労感△・1日の気分％）すべてを、**5刻みのドラムロール（またはセレクトボックス）**で選ぶ。値は5から100までの**全20段階**（5、10、…、100）で、テキスト入力や1点単位の細かい入力は不要にする。手書きの記録表の「ざっくりとした主観的な記入」の感覚を再現し、気分が落ちているときでも直感的に選べるようにする。
- スマホの選択肢の先頭には、未入力に戻すための「未入力」を置く（20段階には数えない）。選択を確定したときに、その項目だけを R-03 で送る。
- 選択を解除すると未入力に戻せる。
- 保存のタイミング: 選択した時点で、その項目だけを R-03 で送る。

## 3. API

R-03（[F-04](F-04_3食食事記録・日記入力.md) の定義）を使う。

```json
// 入力
{ "morning_mood": 30, "fatigue": 15, "day_mood": 35 }
// 入力（未入力に戻す）
{ "day_mood": null }
```

| 検証 | 内容 |
| :--- | :--- |
| `morning_mood` / `fatigue` / `day_mood` | 任意（null 可）、整数、5〜100、5の倍数 |

| ステータス | 条件 |
| :--- | :--- |
| 422 | 範囲外（0、105）、5の倍数でない（33）、整数でない |

## 4. データ

- `daily_summaries.morning_mood` / `fatigue` / `day_mood`（tinyint unsigned、NULL 可）。5の倍数であることはアプリ側で検証する。

## 5. 振る舞い

- 保存の流れは F-04 と同じ。保存に成功したら、F-06 のグラフを再描画する（サーバーからの再取得はせず、画面の状態を更新する）。`day_mood` は右端の列に反映する。

## 6. 受け入れ条件とテスト観点

| 受け入れ条件 | 観点 |
| :--- | :--- |
| 5〜100の5刻みで3項目を保存でき、再表示で同じ値が出る | 正常: 朝の気分30、疲労感15、1日の気分35 |
| 未入力に戻せる | 正常: null |
| 範囲外・5刻みでない値は拒否される | 異常: 0、3、33、105、"abc"、30.5 |
| 境界の値が通る | 境界: 5 と 100 |
| 朝の気分・疲労感の保存でグラフが更新される | 手動確認（F-06） |
| 1日の気分は右端の列に出て、グラフには載らない | 手動確認（F-06・F-07） |
| スマホで3項目がドラムロール（またはセレクト）で選べ、値が5から100の全20段階である | 手動確認（5、10、…、100。テキスト入力はできない） |
| スマホで「未入力」を選ぶと未入力に戻る | 正常: 手動確認（R-03 に null が送られる） |
