# F-08 提出用PDF保存・ダウンロード — 機能設計書

> 共通事項は [設計書](../設計書.md) を参照。プレビューは [F-07](F-07_PDF出力プレビュー.md)。

| 項目 | 内容 |
| :--- | :--- |
| 機能ID / 優先度 | F-08 / 必須 |
| 画面 | W-05 PDFプレビュー画面 |
| API | R-01 週の取得。PDF 化はブラウザの印刷機能 |
| テーブル | users、weeks、daily_summaries、activity_segments（R） |

## 1. 概要

W-05 の印刷ボタンから、ブラウザの印刷機能を呼び出し、A4横向き**1ページ**で PDF として保存（または紙に印刷）できる。ログインしたすべての利用者が、追加料金なしで保存・印刷できる（未ログインでは W-05 を含むすべての画面・API にアクセスできない）。

## 2. 画面（W-05 の操作）

W-05 の印刷ボタンを押すと `window.print()` を呼ぶ。印刷ダイアログの送信先で「PDFに保存」を選んで保存する。

| 項目 | 内容 |
| :--- | :--- |
| ファイル名 | 印刷前に `document.title` を `RePace_2026-11-02_週` の形式（週の開始日）にする。多くのブラウザで PDF の既定のファイル名になる |

- 印刷用の CSS: `@page { size: A4 landscape; margin: 10mm; }`、背景色の印刷（`print-color-adjust: exact`）、改ページの禁止（1週間を1枚に収める）、操作用のボタンを非表示にする。
- フォント: システムの日本語フォントを指定する（Web フォントの埋め込みはしない）。端末で表示が変わらないよう、`'Hiragino Sans', 'Yu Gothic', 'Noto Sans JP', sans-serif` の順で指定する。
- 注意書き: 印刷ダイアログで「用紙サイズ: A4」「向き: 横」「余白: なし／標準」「背景のグラフィック: オン」を確認するよう、画面に小さく示す。
- **スマホ（iPhone など）**: プレビューの印刷ボタン（または Safari の共有メニューの「プリント」）で印刷ダイアログを開き、端末標準の「PDF として保存」や共有の機能でファイルに保存する。サーバーには保存せず、追加料金も不要。画面の縮小表示（F-07 の 2.1）は印刷に影響しない。
- W-05 以外の画面（W-03・W-06 など）を印刷しても、生活記録表の印刷としては出力されないよう、`@media print` で内容を隠し、「印刷は W-05（PDF プレビュー）から行ってください」を出す。

## 3. API

専用の API はない。R-01 のデータを F-07 と共通で使う。

## 4. データ

- 参照のみ（F-07 と同じ）。サーバーに PDF を保存しない。

## 5. 振る舞い

- 印刷ダイアログが開くまでの流れは F-07 のシーケンスのとおり。
- ブラウザの印刷が使えない場合（アプリ内ブラウザなど）は、「ブラウザで開いて印刷してください」と案内する。

## 6. 受け入れ条件とテスト観点

| 受け入れ条件 | 観点 |
| :--- | :--- |
| ログインした利用者が印刷ボタンを押すと、印刷ダイアログが開き、A4 横向きで PDF として保存できる | 正常: 手動確認 |
| 未ログインでは W-05 を開けず、W-01 へ遷移する | 異常: 手動確認（API は 401。設計書 7.2 の自動テスト） |
| W-05 以外の画面を印刷しても、生活記録表は出力されない | 異常: 手動確認 |
| ボタンなどの操作要素が PDF に含まれない | 正常: 手動確認 |
| 1週間分が必ず A4 横向き1ページに収まる（2ページ以上にならない） | 境界: 長い入力が多い週でも1ページ。保存した PDF のページ数が1（手動確認） |
| Chrome と Safari で余白・日本語フォント・グラフが崩れない | 手動確認 |
| iPhone の Safari で、印刷ボタンから A4 横向き1ページの PDF を保存できる | 正常: 手動確認（実機。仕様チェックリスト Q-50） |
| 保存されたファイル名に週の開始日が入る | 手動確認（ブラウザによって異なることを許容） |
