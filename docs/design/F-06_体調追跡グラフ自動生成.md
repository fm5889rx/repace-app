## 1. 概要

記録された朝の気分（◯）と疲労感（△）を、週の開始曜日から始まる7日分の折れ線グラフに自動で描く。入力の変更に連動して即時に更新される。グラフはフロントエンドで描画する（サーバーは値を返すだけ）。

## 2. 画面（グラフの仕様）

| 項目 | 仕様 |
| :--- | :--- |
| 横軸 | 週の7日（開始曜日から順に、原紙と同じ `（土）（日）…（金）` の形式） |
| 縦軸 | 10〜100（数字の目盛りは10刻み。補助線は5刻み。原紙と同じ） |
| 朝の気分（◯） | 丸のマーカーと実線で結ぶ。色は黒 |
| 疲労感（△） | 三角のマーカーと破線で結ぶ。色は赤（原紙と同じ。色だけに頼らず形と線種でも区別する） |
| 未入力の日 | 点を打たず、線も途切れさせる（前後の点を結ばない） |
| 凡例 | 「◯ 朝の気分」「△ 疲労感」を表示する |
| 描画方式 | インラインの SVG（印刷でぼやけず、ベクターのまま出力できる） |
| W-03 / W-05 | 同じコンポーネントを使う。W-05 では A4 横向きの用紙に収まる大きさにする |

- 「1日の気分」（％）はグラフには載せない（右端の列に数値で表示する。F-05）。
- 色だけに頼らない: マーカーの形（◯／△）と線種（実線／破線）で区別する。
- 代替テキスト: グラフに `role="img"` と `aria-label` を付け、日ごとの数値を含む非表示の表を併記する。

## 3. API

専用の API はない。R-01 の `days[].summary.morning_mood` / `fatigue` を使う。

## 4. データ

- `daily_summaries.morning_mood` / `fatigue` を参照する（週の日付範囲）。

## 5. 振る舞い

- 座標の計算（値→ピクセル、未入力の区切り）は、画面に依存しない関数として切り出す（テストしやすくするため）。
- F-05 で値を保存した時点で、画面上の状態を更新し、グラフを再描画する。
- 週の移動（前週・翌週）で R-01 を再取得し、グラフを描き直す。
- 週のすべてが未入力のときは、軸と凡例だけを表示し、「この週は未入力です」と示す。

## 6. 受け入れ条件とテスト観点

| 受け入れ条件 | 観点 |
| :--- | :--- |
| 気分と疲労感を入力すると、7日分の折れ線に ◯ と △ が反映される | 正常: 7日すべて入力 |
| 未入力の日には点が打たれず、線が途切れる | 境界: 途中の1日だけ未入力 |
| 週の開始曜日を変えると、横軸の並びが変わる | 正常: 土曜→月曜（F-10 と連動） |
| 何も入力していない週でもエラーにならない | 境界: 全日未入力 |
| 1日だけ入力した場合に点だけが表示される | 境界: 1日のみ |
| 印刷してもグラフがぼやけず、◯△の区別がつく | 手動確認（F-07・F-09） |
| 座標計算の関数が期待どおりの座標を返す | 自動: 値5・10・100、未入力の区切り（単体テスト） |
