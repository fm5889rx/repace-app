# F-09 提出用PDF保存・ダウンロード — 機能設計書

> 共通事項は [設計書](../設計書.md) を参照。プレビューは [F-07](F-07_PDF出力プレビュー.md)、決済は [F-08](F-08_Stripe決済連携.md)。

| 項目 | 内容 |
| :--- | :--- |
| 機能ID / 優先度 | F-09 / 必須 |
| 画面 | W-05 PDFプレビュー画面 |
| API | R-01 週の取得、A-04 ユーザー情報（`pdf_unlocked`）。PDF 化はブラウザの印刷機能 |
| テーブル | users、weeks、daily_summaries、activity_segments（R） |

## 1. 概要

W-05 の印刷ボタンから、ブラウザの印刷機能を呼び出し、A4横向き**1ページ**で PDF として保存（または紙に印刷）できる。**Stripe 決済に成功した利用者（`pdf_unlocked` が true）のみ**、保存・印刷できる。未決済の利用者は、プレビューは見られるが、保存・印刷はできない。開発中・評価中・本番で、この動作は変わらない。

## 2. 画面（W-05 の操作）

| 状態 | 画面の動作 |
| :--- | :--- |
| 決済済み | 印刷ボタンが有効。`window.print()` を呼ぶ。印刷ダイアログの送信先で「PDFに保存」を選んで保存する |
| 未決済 | 印刷ボタンは無効。代わりに決済導線（「PDFを保存する（500円）」。F-08）を表示する。印刷（`@media print`）では、生活記録表の代わりに「PDF の保存・印刷には決済が必要です」を出す（ブラウザのメニューや Ctrl+P で印刷しても、生活記録表は出力されない） |

| 項目 | 内容 |
| :--- | :--- |
| ファイル名 | 印刷前に `document.title` を `RePace_2026-11-02_週` の形式（週の開始日）にする。多くのブラウザで PDF の既定のファイル名になる |

- 印刷用の CSS: `@page { size: A4 landscape; margin: 10mm; }`、背景色の印刷（`print-color-adjust: exact`）、改ページの禁止（1週間を1枚に収める）、操作用のボタンを非表示にする。
- フォント: システムの日本語フォントを指定する（Web フォントの埋め込みはしない）。端末で表示が変わらないよう、`'Hiragino Sans', 'Yu Gothic', 'Noto Sans JP', sans-serif` の順で指定する。
- 注意書き: 印刷ダイアログで「用紙サイズ: A4」「向き: 横」「余白: なし／標準」「背景のグラフィック: オン」を確認するよう、画面に小さく示す。
- W-05 以外の画面（W-03 など）を印刷しても、生活記録表の印刷としては出力されないよう、`@media print` で内容を隠し、「印刷は W-05（PDF プレビュー）から行ってください」を出す。

## 3. API

専用の API はない。R-01 のデータを F-07 と共通で使い、A-04 の `pdf_unlocked` で保存・印刷の可否を判断する。

## 4. データ

- 参照のみ（F-07 と同じ）。サーバーに PDF を保存しない。
- 保存・印刷の可否は `users.pdf_unlocked_at`（F-08）から決まる。

## 5. 振る舞い

- 印刷ダイアログが開くまでの流れは F-07 のシーケンスのとおり。決済済みの場合のみ印刷ボタンが有効になる。
- 未決済の制限は、ブラウザ側（画面と `@media print`）の制御である。ブラウザの開発者ツールなどを使う技術に詳しい利用者は、回避できる可能性がある（完全な防止は目的としない。仕様チェックリスト 35）。
- ブラウザの印刷が使えない場合（アプリ内ブラウザなど）は、「ブラウザで開いて印刷してください」と案内する。

## 6. 受け入れ条件とテスト観点

| 受け入れ条件 | 観点 |
| :--- | :--- |
| 決済済みの利用者が印刷ボタンを押すと、印刷ダイアログが開き、A4 横向きで PDF として保存できる | 正常: `pdf_unlocked` が true。手動確認 |
| 未決済の利用者は、印刷ボタンが無効で、決済導線が表示される | 正常: `pdf_unlocked` が false。手動確認 |
| 未決済の利用者がブラウザの印刷（Ctrl+P など）を実行しても、生活記録表は出力されず、決済が必要な旨が出る | 異常: 手動確認 |
| 決済が完了して戻ると、印刷ボタンが有効になる | 正常: F-08 と連動。手動確認 |
| W-05 以外の画面を印刷しても、生活記録表は出力されない | 異常: 手動確認 |
| ボタンなどの操作要素が PDF に含まれない | 正常: 手動確認 |
| 1週間分が必ず A4 横向き1ページに収まる（2ページ以上にならない） | 境界: 長い入力が多い週でも1ページ。保存した PDF のページ数が1（手動確認） |
| Chrome と Safari で余白・日本語フォント・グラフが崩れない | 手動確認 |
| 保存されたファイル名に週の開始日が入る | 手動確認（ブラウザによって異なることを許容） |
